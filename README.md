## Project Overview

This project is a **production-grade, end-to-end data engineering and business intelligence analysis** of the Sample Superstore dataset — a four-year (2014–2017) record of US retail transactions across Furniture, Office Supplies, and Technology categories.

The project is built from the perspective of a **BI Analyst or Analytics Engineer** delivering insights to a retail leadership team. It combines a modular Python data pipeline, a SQL analytics layer (DuckDB), an interactive Streamlit dashboard, purpose-built analytical data marts, and a consulting-style Jupyter Notebook that moves from raw data to actionable executive recommendations.

This is not a tutorial project. Every analytical decision is documented with a business rationale, and every finding is connected to a management recommendation.

---

## Business Questions Answered

1. **Where is the business making and losing money?** — Category, sub-category, and product-level profitability analysis
2. **Is the discounting strategy sound?** — Threshold analysis of discount bands vs profit destruction
3. **Which geographies are underperforming?** — State and regional profitability with loss concentration mapping
4. **Which customer segments deserve investment?** — Segment-level margin quality and discount behaviour
5. **What operational patterns compound underperformance?** — Shipping mode efficiency and lead time analysis
6. **What should management do?** — Prioritised, evidence-based strategic action framework

---

## Key Findings

| Finding | Insight |
|---------|---------|
| **High-discount orders destroy $135K/yr** | Orders with discounts >=30% have an 80%+ loss rate in Furniture — a policy failure, not a market problem |
| **Tables and Bookcases are structurally loss-making** | These sub-categories are loss-making at nearly every discount level; pricing reform is required |
| **4 states destroy $71.9K combined** | Texas, Ohio, Pennsylvania, and Illinois are net value destroyers despite meaningful revenue |
| **Technology drives 51% of profit on 36% of revenue** | The business's most scalable engine — and its most under-protected asset |
| **The Central region underperforms by 4+ margin points** | 8% margin vs 12.5% company average; discount discipline investigation needed |
| **18.7% of all order lines lose money** | Nearly 1 in 5 transactions destroys value — concentrated in high-discount, Furniture orders |

---

## Strategic Recommendations

1. **Implement a three-tier discount approval matrix** — discounts above 30% require VP sign-off
2. **Conduct territory-level loss investigations** for Texas, Ohio, Pennsylvania, and Illinois
3. **Review Furniture portfolio pricing** — Tables and Bookcases require price increases or supplier renegotiation
4. **Protect Technology margins** — impose a 20% discount ceiling on all Technology sub-categories
5. **Redesign sales incentives** to reward margin-adjusted revenue, not gross revenue

## Dataset Description

The **Sample Superstore** dataset is a widely used retail analytics benchmark published by Tableau. It contains **9,994 order line items** across **21 columns**, covering:

- Orders placed between **January 2014 and December 2017**
- **49 US states** across 4 regions (East, West, Central, South)
- **3 product categories** (Furniture, Office Supplies, Technology) with **17 sub-categories**
- **793 unique customers** across Consumer, Corporate, and Home Office segments
- Key financials: Sales, Quantity, Discount, Profit per line item

## Methodology

The project follows a **three-layer intelligence pyramid**:

**Layer 1 — Data Engineering**  
Raw CSV → Validated Schema → Cleaned Dataset → Time + Operational Features → Business Features → Analytical Marts

**Layer 2 — Business Intelligence**  
Five analysis dimensions: Financial Performance · Discount Impact · Portfolio Analysis · Geographic Analysis · Operational Analysis

**Layer 3 — Strategic Synthesis**  
Each finding is connected to a specific management recommendation, organised into a prioritised action framework

## Data Marts

Each mart is built in **two implementations** — Python (pandas) and SQL (DuckDB) — demonstrating fluency in both paradigms.

| Mart | Purpose | Supports |
|------|---------|---------|
| `sales_performance_mart` | Monthly/yearly revenue and volume trends | Budget planning, campaign timing |
| `profitability_mart` | Margin by category, sub-category, product | Product rationalisation, pricing |
| `customer_segment_mart` | Performance by segment | Sales force allocation, retention |
| `regional_performance_mart` | Sales and profit by region and state | Territory planning, resource allocation |
| `discount_impact_mart` | Profitability by discount band and category | Discount policy design |

## How to Run

### 1. Clone the repository
```bash
git clone https://github.com/your-username/superstore-analysis.git
cd superstore-analysis
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Run the full pipeline (Python)
```bash
python pipeline.py
```
This generates the cleaned dataset in `data/processed/` and all five data marts in `data/marts/`.

### 4. Run the full pipeline (SQL)
```bash
python sql/run_sql_pipeline.py
```
Same marts, built entirely in SQL via DuckDB — no pandas required.

### 5. Open the notebook
```bash
jupyter notebook notebooks/superstore_analysis.ipynb
```
Run all cells from top to bottom. Charts will be saved to `outputs/figures/`.

### 6. Launch the interactive dashboard
```bash
streamlit run dashboard.py
```
Opens a browser with live KPIs, trend charts, and interactive filters by year, category, region, and segment.

### 7. Run the test suite
```bash
pytest tests/ -v
```
